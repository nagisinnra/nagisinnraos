システム内部の
コアコンポーネント。

小さなモジュールの積み重ねが、ひとつの完成されたOSを形作ります。現在も継続的に進化を続けています。

01 / KERNEL 32-bit x86 カーネル

i386互換のプロテクトモードを中心に設計された、軽量でシンプルな独自カーネル構造。

02 / STORAGE FAT12 ファイルシステム

ファイルやアプリケーションの読み込み、将来のデスクトップ管理を支えるストレージ基盤。

03 / SYSCALL INT 80h システムコール

ユーザーアプリケーションとOSカーネルを安全につなぐシステムコールインターフェース。

04 / DESKTOP ネイティブ GUI デスクトップ

ウィンドウ描画、タスクバー、各種アプリを備えた独自のグラフィカル環境。

05 / APPS プログラム & ゲーム

システム上で動作する独自ユーティリティやミニゲームを実行可能な環境を構築。

06 / NEXT さらなる拡張へ

メモリ管理の高度化、マルチタスク、USB、FAT32、ネットワーク対応を順次計画中。
