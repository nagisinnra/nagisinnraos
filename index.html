Inside
the system.

Small components become a complete operating system. The project is evolving continuously.

01 / KERNEL32-bit x86

Designed around i386-compatible protected mode and a lightweight kernel architecture.

02 / STORAGEFAT12

A real filesystem layer for files, applications and future desktop file management.

03 / SYSCALLINT 80h

A system-call interface connecting applications with the operating system.

04 / DESKTOPNative GUI

A custom graphical desktop with windows, taskbar and applications.

05 / APPSPrograms & games

The system is being designed to run its own applications, utilities and games.

06 / NEXTMore to come

Memory management, multitasking, USB, FAT32 and networking are part of the roadmap.
